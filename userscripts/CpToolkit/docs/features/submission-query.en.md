# Keep submission filters

[Back to the feature list](../../README.en.md#4-feature-list) ・ [日本語](submission-query.md)

> Keeps search filters when switching between All and My submissions, and shows the language in the filter even when the URL uses different letter case.

## How it works

- Carries over search filters such as the task and language when switching between the All and My submissions tabs
- AtCoder filters language names without regard to case, but the language filter only selects an exact match. When the URL says `python`, the matching `Python` is selected in the filter
