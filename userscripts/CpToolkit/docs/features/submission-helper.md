# 提出補助

[機能一覧へ戻る](../../README.md#4-機能一覧) ・ [English](submission-helper.en.md)

> 貼り付けたコードを提出用に変換します。

**この機能は既定で OFF です。設定画面で有効にしてください。**

<p><img src="../images/submission-helper.png" alt="Local Runner で変換したコード"><br><sub>Local Runner で変換した Java のコード（貼り付け後の折りたたみを ON にした例）。クラス名が <code>Main</code> になり、<code>lib</code> の import はコメントになり、使ったライブラリのクラスが末尾に入ります。</sub></p>

## 使い方

- コード全体を貼り付けると、提出できる形に変換します。編集中のコードへ一部を貼り付けたときは変換しません。
- [Local Runner との連携](local-runner.md)があれば、ページで選んだ言語に合う Local Runner の言語で変換します。変換の内容は Local Runner の設定で決まります。Java ならライブラリの展開と `Main` への改名、ほかの言語なら設定した変換のコマンド（`bundle`）とデバッグ用の変数の書き換えです。
- 言語は、AtCoder と yukicoder ではサイトで選んだ言語、Codeforces では提出欄の言語の選択欄から決めます。AOJ、paiza、Library Checker では言語の選択欄を読まず、エディタが判定した言語を使います。C と C++ の共通の表示のように、エディタから言語を決められないときは変換しません。
- Local Runner との連携が無効なとき、接続できないとき、選んだ言語に対応するコンパイラがないときは、ブラウザーで簡易変換します。Java の処理は下の節のとおりです。Python・C・C++・Go・Rust ではデバッグ用変数だけを書き換えます。**Local Runner が変換エラーを返した場合は元のコードを残し、簡易変換は行いません。**
- 簡易変換でデバッグ用の変数を書き換えるのは、提出補助の詳細設定に名前を入れたときだけです。Java 以外では、ブロックの外にある宣言か代入がちょうど1つのときだけ書き換えます。2つ以上あれば元のコードを残して知らせます。Local Runner での書き換えは、Local Runner の設定の `debugFlag` で決めます。
- 詳細設定で ON にすると、変換したコードをエディタに反映した後に、いちばん外側のブロックとコメントを折りたたみます。入れ子のブロックは折りたたみません。既定は OFF です。キー操作で折りたたむ設定と、提出のキーは[ショートカットキー](keyboard-shortcuts.md)にあります。
- 提出用のヘッダーは[コードのヘッダーとフッター](source-comments.md)が付けます。
- 変換やヘッダーの取得の途中で提出すると、終わるまで待ってから提出します。待つ間に問題・言語・コードが変わったときや、変換に失敗したときは提出しません。失敗したときは、見つからない import の名前か最初のエラーを通知します。

<p><img src="../images/submission-helper-imports.png" alt="見つからない import の通知"><br><sub>見つからない import があると、名前を通知します。「診断の全文」で詳細を開けます。</sub></p>

## Java

Local Runner を使う場合のライブラリ登録、通常の import、**`import static` の制約**は [Local Runner の Java ライブラリの使い方](../../../../local-runner/README.md#ライブラリを使う)を参照してください。

- Java の簡易変換ではパッケージ宣言を削除し、`main` を持つトップレベルの型を `Main` に改名します。起動する型がすでに `Main` なら改名は不要です。字句を基に置き換えるため、型と同名の変数も改名されることがあります。コメントと文字列は保持します。起動する型を決められない場合や、改名で既存の `Main` と衝突する場合、`new A().A` のように同名のメンバーの参照先を判定できない場合は、元のコードを残して知らせます。
- デバッグ用の変数は、起動するクラスの直下にある `boolean 名前 = true` の宣言だけを `false` にします。
- Java の空白や改行は通常の文字で書いてください。同じファイルで `String` という型・型パラメーターを宣言する場合や、別の `String` を明示的に import する場合は、`main` の引数を `java.lang.String[]` または `java.lang.String...` と書いてください。
- 詳細設定にライブラリのパッケージ（例：`lib`）を入れておくと、Local Runner に接続できないときにそのパッケージを import したコードを貼り付けたとき、導入方法へのリンクを通知します。このまま提出するとコンパイルエラーになります。

## 詳細設定

設定画面でこの機能の「詳細設定」を開きます。

| 項目                                                         | 既定値   |
|--------------------------------------------------------------|----------|
| Local Runner がないときに false にするデバッグ用の変数の名前 | （空欄） |
| Local Runner で展開する Java のライブラリのパッケージ        | （空欄） |
| 貼り付け後に、いちばん外側のブロックとコメントを折りたたむ   | OFF      |
