# Local Runner

[機能一覧へ戻る](../../README.md#4-機能一覧) ・ [English](local-runner.en.md)

> コードの変換と実行に使う、手元のサーバーへ接続します。別途、Local Runner の導入が必要です。

## 使い方

- 手元の PC で動く [Local Runner](https://github.com/nsubaru11/competitive-programming-tools/blob/main/local-runner/README.md) へ接続します。[Java の提出補助](java-submit.md)と [Easy Test+](easy-test.md) が使います
- Local Runner は別途導入が必要です。接続先の URL は詳細設定で変えられます
- コードは手元の PC へ送るだけで、外部には送りません

## 詳細設定

設定画面の各機能の「詳細設定」で変えられます。

| 項目 | 既定値 |
|---|---|
| 接続先の URL | `http://localhost:8080` |
