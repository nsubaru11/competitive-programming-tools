# Delayed submission

[Back to the feature list](../../README.en.md#4-feature-list) ・ [日本語](submission-timer.md)

> Submits your code after the specified time.

**This feature is off by default. Turn it on in the settings.**

## How it works

- Adds a "Delayed submission" button next to the submit button on task pages
- Enter the number of minutes and press "Set" to submit the code in the editor when the time has passed. "Cancel" stops it

## Pages

- Task pages
