# Local Runner

[Back to the feature list](../../README.en.md#4-feature-list) ・ [日本語](local-runner.md)

> Connects to the local server used to transform and run code. Local Runner needs a separate installation.

## How it works

- Connects to [Local Runner](https://github.com/nsubaru11/competitive-programming-tools/blob/main/local-runner/README.md) running on your PC. It is used by the [Java submission helper](java-submit.en.md) and [Easy Test+](easy-test.en.md)
- Local Runner needs a separate installation. The server URL can be changed in the detailed settings
- Code is sent only to your own PC, not to any external service

## Detailed settings

Change these under "Detailed settings" of each feature in the settings.

| Setting | Default |
|---|---|
| Server URL | `http://localhost:8080` |
