# ページ幅の拡張

[機能一覧へ戻る](../../README.md#4-機能一覧) ・ [English](wide-layout.en.md)

> ページ中央の幅を、指定した幅に広げます。

## 使い方

- ページ中央の幅を、詳細設定で指定した幅に広げます。幅は `75%` や `1200px` のように書きます。**作者のおすすめは `75%` です**
- 既定では幅が空欄なので、何も変わりません。使うときは幅を指定してください

## 詳細設定

設定画面の各機能の「詳細設定」で変えられます。

| 項目                                                | 既定値 |
|-----------------------------------------------------|--------|
| 幅(例: 75%, 1200px。空欄なら元の幅。おすすめは 75%) | (空欄) |
