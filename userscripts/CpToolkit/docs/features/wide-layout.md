# ページ幅の拡張

[機能一覧へ戻る](../../README.md#4-機能一覧) ・ [English](wide-layout.en.md)

> ページ中央の幅を広げます。

## 使い方

- ページ中央の幅を、詳細設定で指定した幅に広げます。幅は `50%` や `1200px` のように書きます
- 空欄のままなら元の幅のままで、エディタに枠線だけを付けます

## 詳細設定

設定画面の各機能の「詳細設定」で変えられます。

| 項目 | 既定値 |
|---|---|
| 幅(例: 50%, 1200px。空欄なら元の幅) | (空欄) |
