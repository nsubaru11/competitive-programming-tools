# 言語の切り替えボタン

[機能一覧へ戻る](../../README.md#4-機能一覧) ・ [English](language-buttons.en.md)

> よく使う言語をボタンとして並べて保存しておき、1回の操作で切り替えられるようにします。並べる言語は選択欄の下の歯車から選びます。

![言語の切り替えボタン](../images/language-buttons.png)

## 使い方

- **よく使う言語を、ボタンとして並べて保存しておけます**。言語の選択欄の下にボタンが並び、押すと1回でその言語に切り替わります
- 並べる言語は、選択欄の下の歯車から選びます。選んだ言語は保存され、問題ページ、提出ページ、コードテストのどこでも同じボタンが並びます
- 長い言語の一覧から毎回探さずに済みます
