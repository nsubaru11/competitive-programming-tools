# Wider page

[Back to the feature list](../../README.en.md#4-feature-list) ・ [日本語](wide-layout.md)

> Widens the central column of the page.

## How it works

- Widens the central column to the width set in the detailed settings, such as `50%` or `1200px`
- When the width is empty, the original width is kept and only a border is added to the editor

## Detailed settings

Change these under "Detailed settings" of each feature in the settings.

| Setting | Default |
|---|---|
| Width (e.g. 50%, 1200px; empty for the original width) | (empty) |

## Pages

- Every AtCoder page
