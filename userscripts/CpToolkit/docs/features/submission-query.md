# 提出一覧の検索条件の保持

[機能一覧へ戻る](../../README.md#4-機能一覧) ・ [English](submission-query.en.md)

> 提出一覧の「すべての提出」と「自分の提出」を切り替えても、検索条件を保ちます。URL の言語名の大文字と小文字が選択肢と違っていても、言語欄に表示します。

## 使い方

- 提出一覧の「すべての提出」と「自分の提出」のタブを切り替えても、問題や言語などの検索条件を引き継ぎます
- AtCoder は言語名の大文字と小文字を区別せずに絞り込みますが、言語欄は完全に一致する選択肢しか選びません。URL の言語名が `python` のように違っていても、一致する `Python` を言語欄に選びます
