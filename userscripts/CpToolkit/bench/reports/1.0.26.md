# CP Toolkit 1.0.26 の性能

統合前の UserScript 群と、CP Toolkit 1.0.26(コミット `8e3a12e`)を、実際の Tampermonkey で同じ条件で動かして比べた結果です。このファイルは `bench/run.sh` が生成しました。測り方と再現の手順は [bench/README.md](../README.md) にあります。

| 項目 | 値 |
|---|---|
| 計測日 | 2026-11-03 |
| CP Toolkit | 1.0.26(`8e3a12e91ae3`) |
| Tampermonkey | 5.5.1 |
| ブラウザ | Chromium 153.0.8010.12(headless) |
| 環境 | linux 6.18.44-fc-v819、Intel(R) Xeon(R) Processor @ 2.10GHz(4 コア) |
| 計測の回数 | Tampermonkey 1365 回(うち、ページに当てはまるスクリプトがすべて動いた回 1365)、失敗 0 回 |

## 1. 結果の要約

スクリプトなしの状態からの増分を、9ページで合計した値です。小さいほど軽いことを表します。

|  | 旧 nsubaru 版 8本 | CP Toolkit(旧8本と同じ機能) | 旧スクリプト 26本 | CP Toolkit(旧26本と同じ機能) |
|---|---:|---:|---:|---:|
| CPU 時間(Tampermonkey 自身 + UserScript) | 214.1 ms | 415.9 ms | 514.2 ms | 431.6 ms |
| GC 後の JS ヒープ | 3.60 MB | 5.66 MB | 7.68 MB | 7.08 MB |
| 複数のスクリプトや機能が触った要素(シム) | 103 | 60 | 310 | 82 |
| 強制レイアウトの疑い(シム) | 6 | 0 | 7 | 0 |

- 旧スクリプト 26本と比べて、CPU 時間は -16%、メモリは -8%、複数のスクリプトや機能が触った要素は -74% です。
- CPU 時間で CP Toolkit が有意に軽いページ: 問題文(139.7 → 65.9 ms)、解説一覧(118.9 → 58.9 ms)
- CPU 時間で CP Toolkit が有意に重いページ: トップ(15.7 → 36.7 ms)、ユーザー(27.7 → 58.9 ms)
- 旧 nsubaru 版 8本と比べると、CPU 時間は +94%、メモリは +57% です。

有意は、Mann-Whitney U 検定で p < 0.05 のものです。

## 8. 限界

- ページは AtCoder の公開ページ9つを計測の前に録画し、計測ではそれだけを返しました。提出一覧・順位表・提出画面はログインが要るので対象外です。提出まわりの機能(結果の平均、検索条件の保持など)は測れていません。
- Chrome 拡張(Statement Lens、comfortable-atcoder)は UserScript ではないので含めていません。
- クラウドなどの Linux 上の headless Chromium で測りました。絶対値より、条件の間の差を見てください。
- 表の数値は [reports/1.0.26/](./1.0.26/) の JSON にもあります。
